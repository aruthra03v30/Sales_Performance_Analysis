# Sales_Performance_Analysis

## Project Overview
This project analyzes sales performance across regions, categories, products, and time periods using the Superstore Sales dataset.

## Objectives
- Analyze regional sales performance
- Identify top and bottom performing products
- Study seasonal sales trends
- Calculate key business KPIs
- Provide tactical business recommendations

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Key Findings
- Total Revenue: 2,261,536.78
- Total Orders: 4,922
- Total Customers: 793
- Average Order Value: 459.48
- Top Revenue Region: West
- Top Revenue Category: Technology
- Best Sales Month: November
